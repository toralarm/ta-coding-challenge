Setup a interview coding challenge. 

The job of the candidate is to build a simple version of toralarm

AI support is explicitly allowed as part of this task.

## Requirements
- The application 
- Use React and a simple go webserver
- Choose any API that is able to deliver football results



## Special Requirements
When the full implementation is done setup a query parameter called bug-mode=true.
If this parameter is present the application should contain multiple bugs. 
The important info: it should not contain the TOP 5 (or more) of the bugs you have seen or even better produced yourself in your career. 

In the interview you will present how this bug came to live. Questions like:
What was wrong in the engineering job that lead to the bug?
How was it caught?
How long did it exist and why so long or short?
What was the fix?
How would you rate this fix?


This is the most important part of this task and the following interview.
